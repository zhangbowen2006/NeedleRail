# NeedleRail

Standalone MoonBit geometry-to-embroidery compiler. Planned v0.1 boundary:
running paths, two-rail satin, even-odd polygon fill, bounded machine moves,
DST export and SVG proof. Coordinates use integer tenths of a millimetre.

No dependency on prior contest projects. Existing algorithms/formats are not
claimed as inventions. External compatibility and real-machine testing are
distinct; only measured tests will be reported.
