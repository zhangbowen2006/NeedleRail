# 技术解释检查题

参赛者应亲自阅读实现与运行样例，并用自己的话回答以下问题。此文件不是答辩稿或申报书。

1. 为什么用 0.1 mm 整数，DST 单条位移的 -121..121 如何表示？为什么编码 y 时要翻转？
2. running 如何保留折线顶点，为什么细分的分母使用 max_step-2？
3. 两条长度不同的轨道如何按弧长对应？为什么超宽不直接拆成别的针法？
4. 扫描线为什么在一端包含、一端排除边交点？环的方向为什么不影响奇偶孔洞？
5. 有孔的一行为什么必须拆成两个 span，跳针与剪线有何不同？
6. 为什么先验证居中绣框，再编码？机器文件中的换色为何不等于 RGB 颜色？
7. 外部解码证明了什么，没有证明什么？在真实布料上还需要哪些工作？
8. 哪部分参考了 pyembroidery，哪些是本项目实现，许可证如何保留？
9. 若评委指出新同类项目，应如何补充比较或撤回申报，而不是更名重投？
