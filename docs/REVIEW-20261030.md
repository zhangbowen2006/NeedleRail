# 子代理复核与修复记录

2026-10-30，两个子代理分别只读检查核心与工程证据，复现后分工修改，主代理整合复测。没有生成正式申报书，也不保证审核结果。

| 发现 | 实际修复与回归 |
|---|---|
| 相邻缎面轨道回退仍被接受 | 拒绝共线反向边；加入明确反例 |
| 反向或错配轨道能生成交叉扇形，包括非相邻重叠横档 | 检测全部空间候选横档交叉/接触；128 单位网格、候选去重、一百万次比较预算；正常 6001 站测试通过，不采用无界平方扫描 |
| `100.000000000000000001` 被 Double 舍入为 100 | 保留 JSON 数字原文，解码前验证整数字面量；拒绝小数和指数写法。公开 typed API 仍接收 Int32，不受此 JSON 词法规则影响 |
| CLI 第二/第三文件写失败可遗留部分产物 | 完整暂存后不覆盖发布；正常异常回滚自有文件。四种故障注入覆盖部分写入、发布失败、并发创建与替换。不是断电事务或恶意并发安全保证 |
| reader 版本输出被硬编码 | 读取已安装包元数据并要求 pyembroidery 1.5.1，不符合即失败 |
| 孔洞检查仅检测针位，没有检查线段 | 独立射线/线段边界划分 oracle，先证明能抓到端点合法但穿孔的反例；再检验凹形、多孔、斜边、嵌套及三种行距共九个组合的每条缝制线段，并检验环方向不改变结果 |
| 声称不同长度双轨，但样例只是平移等长轨道 | 修改 satin 输入为真正不等长轨，重生成并外部解码；现为 228 缝制针位、232 总记录 |

最终本机结果：Wasm/Wasm GC/JS 各 11 组测试通过；Node 10 组通过；四目标严格检查通过；三个 DST 文件外部解码及 SVG XML 解析通过。Windows Native 仍缺本地编译工具，交由 Linux CI 运行。

初审仍有不能靠代码修复的事项：Mooncakes 尚未登录发布，个人本月提交次数/修改资格未确认，申报正文必须本人完成；没有真实用户访谈或机器打样证据。无同类的检索结果不构成创新性保证。项目应按现有几何编译功能与来源披露申报，不能写成完整工业刺绣平台或全球唯一算法。
